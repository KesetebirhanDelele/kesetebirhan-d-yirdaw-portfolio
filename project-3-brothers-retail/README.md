# 3 Brothers Retail

## Project Overview

Provides a dashboard visualizing sales data and profit margins for informed decision-making.

---

## Business Problem

3 Brothers Retail has experienced significant sales growth of 77% from 2019 to 2020, but profits have only increased by 14%, leading to a shrinking profit margin. This discrepancy poses a challenge for the company to maintain profitability as sales continue to rise.

---

## Objective

- Analyze sales performance across various dimensions.
- Identify trends to inform inventory management and marketing strategies.
- Enhance profitability by addressing the shrinking profit margin.

---

## Tools & Technologies

- Power BI
- Kaggle data source
- Data dictionary
- Calendar table
- Sales by location graph

---

## Project Workflow

- Develop a Power BI dashboard to visualize sales and profit margins.
- Analyze sales data by time, category, subcategory, region, and type.
- Create a data dictionary to illustrate data relationships.
- Identify and resolve data formatting issues, such as date formats.
- Monitor performance and trends using key performance indicators.

---

## Key Insights

- Sales increased from $564k in 2019 to over $1 million in 2020.
- Profit rose from $81k in 2019 to $93k in 2020, indicating a profit margin decline.
- Sales are concentrated in three main regions: the eastern US, West Coast, and Texas.
