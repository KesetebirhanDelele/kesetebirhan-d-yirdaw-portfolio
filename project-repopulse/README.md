# Repo Pulse

## Project Overview

Tracks the status of repositories by collecting snapshots and generating reports for effective sprint management.

---

## Business Problem

RepoPulse helps software development teams track the status of their GitHub repositories, providing insights into sprint progress and repository health. This is crucial for teams looking to manage their workflows efficiently and identify potential issues before they escalate.

---

## Objective

- Collect snapshots of GitHub repositories to assess their current status.
- Generate detailed reports to inform team members about sprint progress.
- Provide a user-friendly dashboard for managing and auditing repositories.

---

## Tools & Technologies

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- Uvicorn
- pytest

---

## Project Workflow

- Set up the environment and database connection using a configuration file.
- Run snapshot collection to gather data from registered GitHub repositories.
- Generate weekly reports summarizing repository statuses and risks.
- Access a web dashboard to manage repositories and view insights.

---

## Key Insights

- Utilized a multi-technology stack to streamline the application lifecycle, enhancing maintainability.
- Implemented persistent data storage for efficient retrieval of repository snapshots.
- Designed a user-friendly web interface that simplifies repository management and reporting.
