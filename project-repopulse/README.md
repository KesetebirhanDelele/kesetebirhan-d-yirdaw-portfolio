# Repo Pulse

## Project Overview

Tracks the status of software development sprints by collecting data and generating analysis reports.

---

## Business Problem

RepoPulse addresses the challenge of tracking software development sprint statuses for teams managing multiple GitHub repositories. It provides insights into repository health and progress, helping teams identify risks and areas needing attention.

---

## Objective

- Collect and analyze data from GitHub repositories to track sprint progress.
- Generate comprehensive reports to facilitate decision-making and risk management.
- Provide a user-friendly dashboard for real-time monitoring of repository statuses.

---

## Tools & Technologies

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- Uvicorn
- pytest

---

## Project Workflow

- Set up the environment and configure database connections.
- Collect snapshots of repository data based on user-defined configurations.
- Generate weekly and deep-dive reports for analysis and risk assessment.
- Display repository statuses and insights through a web dashboard.

---

## Key Insights

- Utilized a modular architecture to manage complexity across multiple system components, enhancing maintainability.
- Implemented persistent data storage to ensure reliable retrieval of historical repository data for analysis.
- Designed a user-friendly web interface that simplifies repository management and reporting for non-technical users.
